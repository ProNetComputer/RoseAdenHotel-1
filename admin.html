💡 كيف يعمل نظام النشر السحابي المباشر؟

يقوم هذا النظام بربط لوحة التحكم بمستودع المشروع على GitHub مباشرة عبر GitHub REST API. عند الضغط على زر النشر، يتم تشفير كافة التعديلات في ملف data.json وعمل Commit آلي للمستودع، ليقوم الموقع بجلب التحديثات تلقائياً لجميع الزوار حول العالم.

🔑
* يمكنك استخراج الرمز من إعدادات GitHub (Settings ➔ Developer Settings ➔ Personal Access Tokens مع صلاحية repo).

💻

ملف البرمجة المدمج (js/data.js)

يولّد ملف data.js محدثاً بالكامل لتستبدل به الملف الموجود داخل مجلد js/ فتصبح تعديلاتك هي الافتراضية دائماً حتى بدون إنترنت.
