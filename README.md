## 📌 نبذة عامة عن المشروع

تم تطوير هذا المشروع لتحويل الصفحة البسيطة السابقة لموقع **فندق روز عدن السياحي (الفرع الأول والأقدم والأعرق)** إلى **منظومة برمجية فندقية متكاملة متعددة الصفحات (Multi-Page Web Application)**، مزودة بلوحة تحكم إدارية احترافية (`admin.html`) تمكن إدارة الفندق من إضافة وتعديل وحذف الغرف، متابعة وتأكيد طلبات الحجز، مراسلة النزلاء مباشرة عبر واتساب، تعديل بيانات وهوية الفندق الحية، إدارة معرض الصور والتقييمات، وتصدير واستيراد النسخ الاحتياطية بصيغة `JSON`.

المشروع يتبنى نفس النمط البرمجي الراقي والهوية البصرية المعتمدة في مشاريع فنادق روز عدن، مع دمج منظومة الطاقة والتكييف المستمر 24/7، وشبكة الألياف الضوئية (Fiber) والإنترنت الفضائي العالمي ستارلينك (Starlink)، والتحويلات الهاتفية الداخلية (`EXT: 701` لطيرمانة ومجلس VIP، و `EXT: 444` لخدمة الغرف والمطعم).

## 🌟 أبرز مميزات وخصائص الموقع

1. **تصميم متعدد الصفحات متكامل (Multi-Page Architecture):**
   - انتقال فوري وسلس بين كافة أقسام الفندق عبر روابط مخصصة وعناوين نقية.
2. **ثنائية اللغة التفاعلية (عربي / English):**
   - تبديل فوري للغة بنقرة زر واحدة مع تحويل اتجاه الصفحة كاملاً (`RTL` للعربية و `LTR` للإنجليزية).
3. **الوضع الليلي والنهاري (Dark / Light Modes):**
   - دعم التبديل التلقائي أو اليدوي بين الوضع الليلي الملكي الفخم والوضع النهاري المشرق مع حفظ الخيار في المتصفح.
4. **محرك حجز فوري عبر واتساب (Instant WhatsApp Booking):**
   - نافذة منبثقة تفاعلية لاختيار التواريخ وعدد النزلاء وحساب التكلفة التقديرية بدقة بالريال اليمني والسعودي، مع إنشاء رسالة واتساب منسقة وموجهة مباشرة إلى رقم الفندق المعتمد `+967 780000676`.
5. **دليل التحويلات الداخلية المتصل:**
   - إبراز تحويلات الفندق الأساسية:
     - **تحويلة 701:** استقبال طيرمانات VIP والمجلس العام.
     - **تحويلة 444:** خدمة الغرف والمطعم على مدار 24 ساعة.
     - **تحويلة 100:** الاستقبال العام وعلاقات النزلاء.
     - **تحويلة 200:** إدارة الحجوزات والتسكين.
6. **معرض صور حقيقي وعارض Lightbox:**
   - استعراض الصور الفندقية الأصلية بدقة عالية مع إمكانية التكبير والتنقل.
7. **الهوية الرسمية لشركة برونت كمبيوتر:**
   - تذييل موحد ومعتمد للمهندس عمار محمد سعيد الأسدي بكافة بيانات الشركة وعناوينها وهواتفها.

## ⚙️ دليل لوحة التحكم الاحترافية (`admin.html`)

- **رابط اللوحة:** افتح ملف `admin.html` في المتصفح أو اضغط على زر "لوحة التحكم" في القائمة العلوية.
- **كلمة المرور الافتراضية:** `rose1admin` (أو `admin2026`).

### وظائف لوحة التحكم:
1. **لوحة المؤشرات (Overview):**
   - إحصائيات حية لعدد الغرف (72 غرفة)، الغرف المتاحة، الحجوزات النشطة، والطلبات قيد المراجعة.
   - رصد حالة الطاقة والتكييف والإنترنت الفضائي ستارلينك.
2. **إدارة الغرف والأجنحة (Rooms Manager):**
   - إضافة غرفة جديدة، تعديل الأسعار، تعديل الأسماء باللغتين، تغيير الدور، السعة، وتحديث الصور.
   - تبديل حالة الغرفة بنقرة واحدة (متاحة / محجوزة / صيانة).
   - حذف الغرف غير المرغوبة.
3. **سجل الحجوزات (Bookings Manager):**
   - استعراض كافة الحجوزات الواردة من نماذج الموقع.
   - زر محادثة واتساب فوري مع النزيل برسالة مجهزة مسبقاً.
   - تأكيد الحجز أو إلغاؤه وحفظ الحالة.
4. **تعديل المحتوى والبيانات الحية (Content & Settings):**
   - تعديل أرقام الهواتف، الواتساب، العناوين، التحويلات (701 و 444)، وتنعكس التعديلات فوراً على كامل صفحات الموقع بفضل الربط المباشر مع `localStorage`.
5. **إدارة معرض الصور (Gallery Manager):**
   - إضافة صور جديدة وحذف الصور القديمة وتصنيفها.
6. **إدارة التقييمات والآراء (Reviews Manager):**
   - مراجعة تقييمات النزلاء، إضافة تقييمات موثقة جديدة، أو حذف التقييمات غير المناسبة.
7. **النسخ الاحتياطي واستعادة البيانات (Backup & Restore):**
   - تصدير كامل بيانات الموقع والغرف والحجوزات بنقرة واحدة كملف `JSON`.
   - استيراد أي ملف نسخة احتياطية سابقة لتحديث بيانات الفندق.
   - خيار استعادة ضبط المصنع الأولي.
