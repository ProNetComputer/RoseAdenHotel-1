## 📌 نبذة عامة عن المشروع

تم تطوير هذا المشروع لتحويل الصفحة البسيطة السابقة لموقع **فندق روز عدن السياحي (الفرع الأول والأقدم والأعرق)** إلى **منظومة برمجية فندقية متكاملة متعددة الصفحات (Multi-Page Web Application)**، مزودة بلوحة تحكم إدارية احترافية متطورة (`admin.html`) تمكن إدارة الفندق من:
1. **التطبيق الفوري المباشر للتعديلات:** بمجرد تعديل أسعار أو بيانات أي غرفة أو إضافة غرفة جديدة في لوحة التحكم، يتم نشرها ورندرتها فورياً على كامل صفحات الموقع (`index.html`, `rooms.html`, إلخ) دون أي تأخير، بفضل محرك الرندرة الديناميكية الحية والبث اللحظي عبر `BroadcastChannel`.
2. **محرك النشر السحابي المباشر إلى GitHub Pages:** إمكانية ربط لوحة التحكم مباشرة بـ GitHub REST API لعمل Commit وتحديث تلقائي لملف `data.json` ومستودع المشروع على GitHub بنقرة زر واحدة.
3. **رفع الصور من جهازك:** دعم سحب وإفلات أو اختيار الصور من الكمبيوتر/الهاتف وتحويلها تلقائياً إلى ترميز رقمي مدمج (Base64) وحفظها في قاعدة بيانات الفندق.
4. **استوديو تخصيص تصميم ومظهر الموقع:** التحكم المباشر في ألوان الفندق الملكية، الخطوط، استدارة الحواف، وإظهار أو إخفاء أقسام الموقع.
5. **إدارة المستخدمين وصلاحيات الدخول:** دعم حسابات متعددة (المدير العام، مدير العمليات، موظف الاستقبال) مع نافذة مخصصة لتغيير وتأكيد كلمات المرور.

## ⚡ كيف تعمل المزامنة اللحظية والنشر المباشر؟

1. **الرندرة الحية في المتصفح (Instant Live Dynamic Rendering):**
   * عند قيام المشرف بتعديل سعر أي غرفة (مثلاً من 85,000 إلى 95,000 ريال) أو إضافة غرفة جديدة أو تغيير حالتها في `admin.html`، يتم حفظ البيانات في `localStorage` وإطلاق إشعار بث فوري عبر `BroadcastChannel('rose1_hotel_live_sync')`.
   * أي تبويب مفتوح لصفحات الموقع (`index.html`, `rooms.html`) يستقبل الإشعار فوراً ويقوم بإعادة بناء بطاقات الغرف والأسعار لحظياً أمام المستخدم دون الحاجة حتى لإعادة تحميل الصفحة!

2. **النشر السحابي المباشر إلى GitHub Pages (GitHub API Auto-Sync):**
   * من داخل تبويب **"🚀 النشر السحابي (GitHub)"** في لوحة التحكم، يمكنك إدخال رمز الوصول الشخصي (GitHub Token) مرة واحدة.
   * اضغط على زر **"نشر وتحديث بيانات الموقع على GitHub Pages الآن"**، وسيقوم النظام بالاتصال مباشرة بـ GitHub REST API وتحديث ملف `data.json` وعمل `Commit` آلي، لتنعكس التعديلات على الرابط العالمي المنشور خلال ثوانٍ معدودة.
   * كما يتوفر دائماً زر تنزيل يدوي لملف `data.json` المحدث لرفعه للمستودع في أي وقت.
